# 🎮 Emoji Memory Game

A fun and interactive **Emoji Memory Game** built with React and Vite. Test your memory by flipping cards, finding matching emoji pairs, and completing the game with as few moves as possible!

🔗 **Live Demo:** [Play Emoji Memory Game](https://jatin1412.github.io/emoji-memory-game/)

## ✨ Features

- 🧠 **Memory Challenge:** Find matching pairs of hidden emoji cards.
- 🎯 **Multiple Difficulty Levels:** Choose Easy, Medium, or Hard.
- ⏱️ **Timer:** Track the time taken to complete the game.
- 🔢 **Move Counter:** Keep track of your moves.
- 🔄 **Card Flip Animation:** Interactive card-flipping effects.
- ⏸️ **Pause Functionality:** Pause the game when needed.
- 🏆 **Win Screen:** Get feedback when all matching pairs are found.
- 📱 **Responsive Design:** Play on mobile, tablet, and desktop.
- 🎨 **Modern UI:** A clean and engaging interface with interactive styling.

## 🛠️ Tech Stack

- **React** — Building reusable UI components and managing application state.
- **JavaScript (ES6+)** — Implementing game logic and interactions.
- **Vite** — Fast development server and production build tool.
- **HTML5** — Structuring the application.
- **CSS3** — Styling, responsive layouts, animations, and card-flip effects.
- **ESLint** — Maintaining code quality and identifying potential issues.
- **Git & GitHub** — Version control and project hosting.
- **GitHub Pages** — Deploying the game online.

## 🎮 How to Play

1. Open the [live game](https://jatin1412.github.io/emoji-memory-game/).
2. Choose your preferred difficulty level.
3. Start the game and reveal the hidden emoji cards.
4. Flip two cards at a time to find matching pairs.
5. Remember the positions of previously revealed emojis.
6. Match all pairs to win the game!

## 🚀 Run Locally

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Jatin1412/emoji-memory-game.git
```

**2. Navigate to the project folder**

```bash
cd emoji-memory-game
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL shown in your terminal to play the game.

### Build for Production

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
